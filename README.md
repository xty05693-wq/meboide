# meboide

Лёгкая IDE / редактор кода в браузере. React + Vite + CodeMirror 6.

## Запуск (веб-версия)

```
npm install
npm run dev
```

Откройте http://localhost:5173 в **Chrome** или **Edge**.

## Сборка .exe (десктоп-версия)

```
npm run dist
```

Готовый файл: `release\meboide 0.1.0.exe` (portable, один файл — просто запустить).

Запуск без упаковки: `npm run app` (собирает и открывает окно Electron).

В десктоп-версии доступ к файлам идёт напрямую через Node.js (fs) — без
разрешений браузера, работает любая папка на диске.

## Возможности

- Открытие реальной папки с диска (File System Access API) и дерево файлов
- Вкладки, индикатор несохранённых изменений, закрытие средней кнопкой мыши
- Подсветка синтаксиса: JS/TS/JSX/TSX, HTML, CSS/SCSS/LESS, JSON, Markdown, Python
- Автодополнение, свёртка кода, поиск по файлу, тёмная тема
- Создание файлов/папок, удаление через контекстное меню
- `Ctrl+S` — сохранить (в файл, или «Сохранить как» для несохранённых)
- Без папки: черновые файлы в памяти (в Firefox — скачивание файла)
